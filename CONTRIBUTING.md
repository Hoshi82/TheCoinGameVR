# Contributing

Bug reports and focused pull requests are welcome. Use the issue templates and
describe your game version, mod version, headset/OpenXR runtime, and controller.
Provide reproducible steps and relevant logs after checking them for private data.

Follow [the build guide](docs/BUILDING.md). Keep game binaries, proprietary SDK
headers, generated builds, logs, and local paths out of commits. Preserve existing
aim, HUD, controller, grabbing, and scene transition behavior. Include headset
test results where available; do not imply hardware testing you did not perform.

Keep documentation and user-facing messages in English. Third-party components
must retain their original licenses and attribution. Contributions to original
project code are submitted under this repository's MIT license.
