# The Coin Game VR v0.0.89

First public download of the tested VR mod by Hoshi82.

## Install

1. Install [Microsoft Visual C++ v14 Redistributable X64](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist/).
2. Close the game and back up any existing mod/loader files.
3. Extract **TheCoinGameVR-v0.0.89-Windows-x64.zip** directly beside
   `TheCoinGame.exe`.
4. Start the headset/OpenXR runtime and launch the game through Steam.

**MelonLoader 0.7.3 is included. No separate MelonLoader download is needed.**
No Visual C++ runtime DLLs, game files, personal settings, or old logs are bundled.

## Included behavior

Stereo OpenXR rendering, automatic VR startup, headset aim, mouse/gamepad
controls, physical grabbing, F9/Xbox View recentering, head-following 16:9 menus
at 2 meters, and runtime-recommended render resolution at 100%.

**Gamepad or mouse/keyboard only. 6DoF motion-controller support is not implemented.**
It may be explored in a future update, with no announced schedule.

Tested with The Coin Game 1.0.11, Windows 10, Bigscreen Beyond 2e, SteamVR/OpenXR,
and an Xbox-compatible controller. The ZIP was tested by reinstalling after a
normal-game startup check. Compatibility with every other setup is not guaranteed.

Download the mod ZIP below, **not** GitHub's automatically generated source archives.
Checksum file is provided alongside it.
